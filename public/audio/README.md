# ساختار فایل‌های صوتی (Audio Assets)

در نسخه اولیه، تمام افکت‌های صوتی چرتکه و بازخوردها به صورت بلادرنگ با Web Audio API سنتز می‌شوند تا هیچ فایل خارجی یا خطای بارگذاری وجود نداشته باشد.
برای جایگزینی با فایل‌های ضبط‌شده حرفه‌ای در آینده، فایل‌های زیر را در این پوشه قرار دهید و در `src/lib/audioEngine.ts` آدرس آن‌ها را فعال کنید:

- `bead-click.mp3`: صدای چوبی ملایم حرکت مهره
- `ui-tap.mp3`: صدای کلیک دکمه‌ها
- `success.mp3`: صدای تشویق پاسخ درست
- `try-again.mp3`: صدای نرم راهنمایی و تلاش دوباره
- `level-complete.mp3`: صدای پایان موفقیت‌آمیز درس
